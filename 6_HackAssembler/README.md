# HackAssembler



A Hack assembly (`.asm`) to machine code (`.hack`) assembler implemented in C.



## Build



```bash

make

```



All the required files are inside /src directory.
The provided Makefile handles compilation.



## Usage



```bash

./HackAssembler <input>.asm <output>.hack

```



Example:



```bash

./HackAssembler Add.asm Add.hack

```

## Try yourself



the sample_asm_files directory contains some example asm files to test which can be compared against the files inside expected_outputs directory
